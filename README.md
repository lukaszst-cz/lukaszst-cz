Tworzę aplikacje i narzędzia, które mają po prostu ułatwiać pracę. Najczęściej biorę na warsztat rzeczy, które sam chciałbym mieć pod ręką: porządkowanie dokumentów, pilnowanie terminów, proste panele, automatyzację powtarzalnych czynności i rozwiązania dla małych firm.

## O mnie

Mam doświadczenie w IT, DTP i prepress, pracy z dokumentami oraz organizacji procesów. Znam też realia logistyki i pracy operacyjnej, dlatego przy projektowaniu aplikacji zwracam uwagę nie tylko na kod, ale przede wszystkim na to, czy dane rozwiązanie ma sens w codziennym użyciu.

Lubię proste rozwiązania. Jeżeli użytkownik musi długo zastanawiać się, gdzie kliknąć albo co zrobić dalej, to znaczy, że interfejs można jeszcze poprawić.

W swoich projektach często stawiam na pracę lokalną i kontrolę użytkownika nad danymi. Tam, gdzie aplikacja wykonuje ważniejszą operację, wolę najpierw pokazać wynik lub propozycję, a dopiero potem pozwolić ją zatwierdzić.

## Projekty, nad którymi pracuję

### DocPilot

Program do porządkowania dokumentów na komputerze. Czyta PDF-y i skany, korzysta z OCR, pomaga znaleźć terminy, wyszukiwać dokumenty, wykrywać duplikaty i grupować pliki według spraw.

Projekt jest rozwijany jako aplikacja lokalna dla Windows.

[Repozytorium](https://github.com/lukaszst-cz/docpilot) · [strona projektu](https://lukaszst-cz.github.io/operations-office-portfolio/docpilot/) · [wydania](https://github.com/lukaszst-cz/docpilot/releases)

### LifePilot

LifePilot wyrósł z DocPilota. Chodzi o to, żeby program nie kończył pracy na rozpoznaniu dokumentu, tylko pomagał odpowiedzieć na prostsze pytania: co to jest, czy wymaga działania, do kiedy i co warto zrobić jako następne.

W tej chwili jest to rozwijana warstwa projektu DocPilot. Obejmuje między innymi widok „Co teraz?”, kolejkę spraw, terminy i ProofPack.

[Opis projektu](https://github.com/lukaszst-cz/docpilot#lifepilot-preview) · [dokumentacja](https://github.com/lukaszst-cz/docpilot/blob/main/LIFEPILOT.md)

### Aktywnik+

Bezpłatna aplikacja PWA do zapisywania aktywności. Ma tryb osobisty i rodzinny, profile dzieci, raporty, eksport danych oraz opcjonalną synchronizację.

Projekt jest obecnie rozwijany i testowany jako publiczna wersja beta.

[Uruchom Aktywnik+](https://aktywnik-plus.vercel.app) · [repozytorium](https://github.com/lukaszst-cz/aktywnik-plus)

### CzyToŚciema?

Aplikacja do wstępnego sprawdzania podejrzanych wiadomości, linków, ofert, zrzutów ekranu i kodów QR.

Analiza i OCR działają lokalnie w przeglądarce. Program nie otwiera podejrzanych adresów i nie wysyła treści wiadomości na zewnętrzny serwer.

[Repozytorium](https://github.com/lukaszst-cz/czy-to-sciema)

### CoTeraz?

Prywatnie rozwijam też projekt CoTeraz. Jego pomysł jest bardzo prosty: zamiast kolejnej rozbudowanej listy zadań ma pomóc wybrać jedną sensowną rzecz do zrobienia w danej chwili.

Repozytorium jest na razie prywatne.

## Technologie

W zależności od projektu pracuję między innymi z:

Python · FastAPI · SQLite · JavaScript · TypeScript · React · HTML · CSS · SQL

Do tego dochodzą Git i GitHub, GitHub Actions, Vercel, Supabase, Cloudflare, OCR/Tesseract, OpenCV, PWA, WordPress, Excel/CSV, Notion i Obsidian.

Nie staram się dobierać technologii pod samą listę w portfolio. Ważniejsze jest dla mnie to, żeby projekt dało się uruchomić, przetestować i później normalnie używać.

## Jak pracuję nad projektami

Zaczynam od problemu i próbuję rozpisać najprostszy sensowny sposób jego rozwiązania. Potem buduję działającą wersję, sprawdzam ją na typowych i nietypowych przypadkach i dopiero wtedy dokładam następne funkcje.

W projektach, w których operuję na dokumentach lub danych użytkownika, ważne są dla mnie możliwość wykonania kopii, cofnięcie operacji, historia zmian i jasna informacja o tym, co program zrobi.

AI traktuję jako narzędzie. Jeżeli może przyspieszyć analizę, porządkowanie informacji albo przygotowanie następnego kroku, wykorzystuję je. Jeżeli zwykła reguła lub dobrze zaprojektowany formularz wystarczą, nie ma sensu komplikować rozwiązania.
