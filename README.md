## 👋 O mnie

Łączę doświadczenie z **IT, DTP / prepress, organizacji procesów, dokumentów i logistyki** z tworzeniem praktycznych aplikacji oraz automatyzacją pracy.

Najbardziej interesują mnie rozwiązania, które są:

- **proste dla użytkownika** — interfejs ma pomagać, a nie przeszkadzać;
- **użyteczne od pierwszego uruchomienia** — projekt powinien rozwiązywać konkretny problem;
- **local-first tam, gdzie ma to sens** — prywatne dane nie powinny bez potrzeby opuszczać urządzenia;
- **bezpieczne i odwracalne** — najpierw podgląd i decyzja użytkownika, dopiero potem zmiana;
- **testowalne** — automatyczne testy, CI, smoke testy i kontrola regresji;
- **rozwijane iteracyjnie** — kolejne wersje wynikają z realnego workflow, a nie z dokładania funkcji dla samego ich posiadania.

> **Dobry program nie powinien być trudniejszy w obsłudze niż problem, który rozwiązuje.**

## 🔐 Kierunek: local-first i kontrola użytkownika

W wielu moich projektach celowo stosuję podejście **local-first**.

To oznacza, że tam, gdzie jest to możliwe:

- dane są przetwarzane lokalnie;
- wysłanie danych do zewnętrznej usługi wymaga świadomej decyzji;
- operacje zmieniające pliki są poprzedzone podglądem;
- ważne działania pozostawiają historię lub możliwość odzyskania danych;
- aplikacja jasno komunikuje swoje ograniczenia.

Nie traktuję AI jako celu samego w sobie. Interesuje mnie przede wszystkim wykorzystanie go tam, gdzie faktycznie skraca drogę:

**informacja → uporządkowanie → decyzja → działanie.**
