## Jak myślę o projektach

Najpierw rozpisuję proces: **wejście → kontrola → realizacja → dowód → zamknięcie**. Dopiero potem dobieram technologię. Jeżeli wystarczy arkusz lub dobrze zaprojektowany formularz, nie komplikuję rozwiązania. Jeżeli potrzebna jest baza, portal albo aplikacja — buduję je tak, żeby użytkownik wiedział, co ma zrobić dalej.
