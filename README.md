# Łukasz St-cz

**Aplikacje i strony WWW · automatyzacja pracy · dane i procesy operacyjne**

Projektuję i rozwijam praktyczne narzędzia do pracy z dokumentami, informacją i codziennymi zadaniami. Łączę doświadczenie w transporcie, flocie, obsłudze B2B oraz produkcji i DTP z programowaniem, analizą danych i projektowaniem interfejsów.

Rozwijam również **[markę Zielona Marka](https://zielona-marka.pl/)**: stronami internetowymi, modernizacją istniejących witryn, formularzami i prostymi rozwiązaniami dla firm.

## Podejście do pracy

Zaczynam od zrozumienia problemu, danych i użytkownika. Rozpisuję proces, role i sytuacje wyjątkowe, a następnie dobieram rozwiązanie: arkusz, formularz, interfejs, API lub aplikację. Sprawdzam również przypadki błędne, dostępność, zachowanie na telefonie i ochronę danych.

**Technologie:** Python, SQL / SQLite, C# / .NET, JavaScript, TypeScript, React, HTML / CSS, Git / GitHub Actions, Excel oraz narzędzia do automatyzacji i dokumentacji.
